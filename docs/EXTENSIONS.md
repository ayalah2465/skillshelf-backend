# תזכורות להגשה והרחבות — מה נקבע ומה נשאר להמשך

המסמך מבחין בין מימוש שרת לבין דרישות לממשק. אין כאן קוד React, ולכן סעיף של ממשק אינו נחשב למסך שכבר נבנה.

## תזכורות לקראת ההגשה

| תזכורת | חשיבות | מעמד והסבר קצר |
|---|---|---|
| השלמת מסכי React וחיבורם לשרת | קריטית להשלמת הפרויקט | נקבעה מראש; צד הלקוח טרם נבנה |
| השלמת פריסה ובדיקת השרת בכתובת הציבורית לפני ההגשה הסופית | **גבוהה מאוד** | תזכורת שנוספה לאחר המסירה; בדיקה מקומית אינה מוכיחה שהשרת, מסד הנתונים וההורדות פועלים גם בענן. זו המלצת מסירה חשובה, ולא דרישת מוסד נוספת שנמסרה |
| בדיקת health, Swagger, התחברות, הרשאות והורדת קובץ בשרת הציבורי | גבוהה מאוד | חלק מבדיקת הפריסה; מאמתת את זרימת השימוש בפועל |
| בדיקת React מול השרת הציבורי, כולל CORS ומועדפים אישיים | גבוהה מאוד | בדיקת חיבור לפני ההגשה; הצלחת השרת לבדו אינה מוכיחה שצד הלקוח מחובר כראוי |
| בדיקת היעדר סודות ב־GitHub וב־ZIP הסופי | קריטית | נקבעה מראש; מונעת חשיפת סיסמאות, JWT_SECRET וכתובות חיבור פרטיות |
| השלמת מצבי טעינה, הצלחה, שגיאה ורשימה ריקה | גבוהה | נקבעה מראש; חיונית לממשק ברור ושלם |
| הרצת בדיקות ובנייה אחרי שינויי קוד | גבוהה | נקבעה מראש; תוצאות הבדיקות במסירה מתייחסות לגרסה שנבדקה |
| שמירת הרשאת binaries.prisma.sh ופרסום הגדרות סביבת הפיתוח | בינונית; חשובה למשימות עתידיות בסביבה זו | תזכורת סביבתית; הכלי המקומי עובד, אך ההרשאה נשמרה כטיוטה בלבד. אין בכך תנאי להגשת ZIP בסביבה עם גישה רגילה |
| ציון sslmode=verify-full במפורש ב־DATABASE_URL המקומי וב־Render | בינונית; מומלץ לפני ההגשה ובפרט לפני שדרוג תלויות | תזכורת נוספת בעקבות אזהרת SSL בזמן הפריסה. כיום החיבור כבר מאמת את התעודה במלואה; ההגדרה המפורשת שומרת על הכוונה גם בשדרוגים עתידיים. אם מופיע sslmode=require יש להחליפו ב־sslmode=verify-full, להשאיר את שאר הכתובת ללא שינוי ולבדוק את החיבור לאחר העדכון |
| בחינת ההרחבות שלהלן רק אחרי השלמת הבסיס | נמוכה ביחס לדרישות החובה | שומרת על לוח הזמנים; אין צורך בהרחבות כדי לעמוד בדרישות |

הוראות הפריסה נמצאות ב־[START-HERE.md](../START-HERE.md). הפריסה הציבורית ובדיקתה עדיין לא בוצעו בעת הוספת התזכורת.

**המלצה לזמן שנותר:** תחילה להשלים את כל מסכי הבסיס. לאחר מכן לבחור לכל היותר שיפור קטן בממשק, כמו אייקונים, כפתור העתקה או קישור שיתוף. אין צורך להוסיף יכולת חדשה כדי לעמוד בדרישות המקוריות.
