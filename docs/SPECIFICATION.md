# האפיון שנמסר למימוש

## הצורך העסקי

סטודנטים ומפתחים מחפשים קובצי הנחיות ברורים לסוכני AI. SkillShelf מרכז משאבים עם הסבר, כלי נתמך והוראות שימוש, ומאפשר לשמור ולהוריד אותם. האתר אינו מפעיל את הקבצים ואינו מספק מנוע AI.

אורח צופה בקטלוג; משתמש רגיל מוריד ושומר מועדפים; מנהל מפרסם ועורך. הרשמה עצמית אינה מאפשרת בחירת מנהל.

## התאמה לדרישות

| דרישה | המימוש |
|---|---|
| התחברות | login עם Hash סיסמה ו־JWT מוגבל בזמן |
| שני סוגי משתמשים | USER ו־ADMIN, בדיקה בצד השרת |
| אובייקט מרכזי | Resource |
| לפחות חמישה שדות משמעותיים | שם, תיאור, סוג, קטגוריה, כלי נתמך, הוראות שימוש וקובץ |
| רשימה | קטלוג עם עימוד |
| הוספה ועריכה | נתיבי מנהל עם טופס וקובץ |
| קטגוריה או שדה בחירה | Category וסוג SKILL/RULE |
| חיפוש, סינון או מיון | חיפוש בשם ובתיאור, סינון סוג וקטגוריה |
| מסד נתונים אמיתי | PostgreSQL; גם תוכן הקבצים נשמר בו |
| מניעת גישה למידע אישי | מועדפים לפי המשתמש שב־Token בלבד |
| Swagger | OpenAPI 3.0.3, כל 14 הפעולות ו־Authorize |
| בדיקות | בדיקות PostgreSQL ו־HTTP; פירוט תוצאות במסמך נפרד |
| מסירה | מקור, נעילת תלויות, Migrations, Seed ותיעוד בעברית |

## מודל הנתונים

- User: מזהה UUID ראשי, displayName עד 80, email ייחודי ומנורמל עד 254, passwordHash, תפקיד USER כברירת מחדל, createdAt.
- Category: מזהה UUID ראשי ושם ייחודי עד 80.
- Resource: מזהה UUID ראשי, title עד 120, description עד 2000, enum type, supportedTool עד 100, usageInstructions עד 10000, categoryId חובה שמצביע ל־Category, fileName עד 180, fileData בינארי, fileSize מספר שלם, mimeType עד 80, isActive, downloadCount, createdAt ו־updatedAt.
- Favorite: מפתח מורכב userId+resourceId ושעת יצירה. שני המזהים הם מפתחות זרים. המחיקה של חשבון או משאב ברמת DB מוחקת את הקשרים, אך אין נתיב מחיקה קבועה בגרסה הזו.

כל השדות האלו אינם null. כמות ההורדות אינה שלילית. גודל הקובץ חייב להתאים למספר הבתים ולהיות בין 1 ל־1048576. מחיקת קטגוריה עם משאבים נחסמת. אין טבלת אחסון או מזהה קובץ חיצוני, משום שנבחרה שמירת BYTEA בתוך Resource למניעת תלות בדיסק זמני.

הקשרים: Category אחת למשאבים רבים; משתמשים ומשאבים קשורים ביחס רבים־לרבים באמצעות Favorite.

## המסכים

קטלוג, פרטי משאב, התחברות והרשמה, מועדפים וניהול. טופס ניהול אחד להוספה ולעריכה. דרישות המסכים ותגובות השרת מפורטות ב־FRONTEND-API-GUIDE.md. מסכים אלו טרם נבנו כאן, בהתאם להגבלה שקוד React ייכתב עצמאית.

## הרשאות ופונקציונליות

כל אדם יכול לקבל קטגוריות, רשימת משאבים פעילים ופרטים. משתמש מחובר יכול להוריד ולנהל את המועדפים שלו. ADMIN יכול גם לנהל משאבים ולראות מוסתרים. הסתרה מחליפה מחיקה: הנתונים נשמרים, אך פרטיהם, הורדותיהם והופעתם במועדפים אינם זמינים לציבור.

הרשימה הציבורית אינה מקבלת userId. פעולות אישיות מזהות בעלות מתוך Token שנבדק ומסד הנתונים. שדות role, fileData ו־downloadCount אינם מתקבלים מטופס מנהל או משתמש.
