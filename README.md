# SkillShelf — שרת לספריית Skills ו־Rules

שרת עצמאי לקטלוג קובצי הנחיות לסוכני AI. המערכת מאפשרת חיפוש, סינון, מועדפים והורדת קבצים. אין התקנה אוטומטית במחשב ואין שירות AI בתשלום כחלק מהפעלת האתר.

**נקודת ההתחלה:** [START-HERE.md](START-HERE.md). לפיתוח צד הלקוח: [FRONTEND-API-GUIDE.md](FRONTEND-API-GUIDE.md).

## מה נכלל

- הרשמה, התחברות עם JWT לשעה כברירת מחדל, ותפקידי USER ו־ADMIN.
- קטלוג ציבורי, פרטי משאב, חיפוש בשם ובתיאור וסינון לפי סוג וקטגוריה.
- עימוד: 12 פריטים כברירת מחדל, עד 24 בעמוד. סדר קבוע: החדשים תחילה.
- מועדפים פרטיים למשתמש המזוהה והורדות המחייבות התחברות.
- ניהול משאבים, החלפת קובץ, הסתרה ופרסום מחדש. אין מחיקה קבועה.
- קובץ UTF-8 אחד לכל משאב, עד 1 MiB, בסיומת md, txt או json. שם הקובץ באנגלית וללא רווחים.
- שמירת הקובץ בתוך PostgreSQL, כך שהעלאות אינן תלויות בדיסק זמני של שירות האירוח.
- מונה בקשות הורדה מאושרות; הוא אינו מעיד שהקובץ נשמר או הופעל במחשב.
- שש קטגוריות ו־18 משאבי הדגמה עם קבצים אמיתיים, כולל Skills ו־Rules ל־Claude Code.
- Swagger ב־`/api-docs`, מסמך `/openapi.json`, ובריאות ב־`/api/health` שבודקת גם את מסד הנתונים.

## טכנולוגיות

Node.js 24 LTS, npm, Express 5, TypeScript strict, PostgreSQL 16, Prisma 6.19.3, מתאם PostgreSQL הרשמי של Prisma, Zod, JWT, bcrypt באמצעות bcryptjs, ו־Vitest. גרסאות מדויקות וקובץ package-lock.json נכללים. Prisma Client משתמש במנוע JavaScript הרשמי; ה־CLI הרגיל של Migrations עדיין עשוי להוריד מנוע רשמי מ־binaries.prisma.sh.

אין קוד React בפרויקט. כל המידע הדרוש לכתיבתו עצמאית נמצא במדריך הלקוח.

## הפעלה קצרה

לאחר התקנת Node.js 24 והכנת PostgreSQL:

```sh
npm ci
```

יש להעתיק `.env.example` ל־`.env` ולהגדיר DATABASE_URL ו־JWT_SECRET. אין להעלות `.env` ל־GitHub.

```sh
npm run generate
npm run db:validate
npm run db:deploy
npm run build
npm start
```

למצב פיתוח עם הפעלה מחדש לאחר שינוי: `npm run dev`.

**אין צורך לשנות את הקוד כדי לבחור ספק PostgreSQL אחר.** החיבור נקבע באמצעות DATABASE_URL. בחיבור ענן יש לפעול לפי הוראות TLS של הספק; אין לבטל בדיקת תעודות.

## נתוני הדגמה וחשבונות

Seed פירושו הכנסת נתוני התחלה. הוא מופעל במפורש, ואינו מופעל בעליית השרת. יש להגדיר ב־`.env` את ארבעת משתני SEED המופיעים בקובץ הדוגמה, עם כתובות בדויות ושתי סיסמאות פרטיות שונות. סיסמה חייבת להכיל 10 תווים לפחות, אות אנגלית גדולה, אות אנגלית קטנה וספרה, ועד 72 בתים ב־UTF-8.

```sh
npm run db:seed
```

נוצרים חשבון מנהל וחשבון משתמש רגיל. רק חשבון חדש יכול לקבל תפקיד דרך ה־Seed. אם הדוא״ל כבר קיים בתפקיד אחר, הפעולה נעצרת. הרצה חוזרת אינה משנה סיסמאות או משאבים שנערכו ואינה משכפלת נתונים. למשתמש הדגמה חדש נוצרים שלושה מועדפים; מחיקתם לא תבוטל בהרצת Seed חוזרת.

המשאבים הם דוגמאות לימודיות מקוריות. יש לבדוק את התאמתם לגרסת הכלי לפני שימוש; לא נטען שהם נבדקו בתוך Claude Code. הורדת Skill מחזירה SKILL.md, עם הנחיות היכן לשמור אותו. הורדת Rule מחזירה קובץ md.

## בדיקות

יש ליצור מסד נתונים נפרד ששמו מתחיל ב־`skillshelf_test_`, להעתיק `.env.test.example` ל־`.env.test` ולהגדיר TEST_DATABASE_URL. הבדיקות מוחקות רק את נתוני היישום במסד הבדיקות שהוגדר. אין להשתמש במסד נתוני היישום או בענן הפעיל כבסיס לבדיקות.

```sh
npm run typecheck
npm run build
npm test
```

בדיקת שרת שכבר פועל, עם חשבון המשתמש מה־Seed:

```sh
npm run smoke
```

הבדיקה האחרונה קוראת נתונים, מתחברת ומורידה קובץ אמיתי; לכן מונה ההורדות משתנה. אין בה פרסום או שינוי משאבים.

## מבנה הקבצים

```text
src/
  auth/          התחברות, אימות JWT והרשאות
  categories/    קטגוריות הקטלוג
  config/        בדיקת משתני סביבה
  database/      Prisma ונתוני הדגמה
  favorites/     מועדפים אישיים
  middleware/    שגיאות והגבלת בקשות
  resources/     משאבים, ולידציה וקבצים
  types/         טיפוסים משותפים
  app.ts         הרכבת Express ו־Swagger
  server.ts      הפעלת השרת וסגירה מסודרת
prisma/          מודל הנתונים ו־Migrations
scripts/         Seed, בדיקת שרת ויצירת תיעוד
tests/           בדיקות מול PostgreSQL אמיתי
docs/            אפיון, אבטחה, הרחבות ותוצאות בדיקה
```

## הגנות ומגבלות ידועות

ההרשאות נבדקות בשרת בכל קריאה מוגנת. בהרשמה אין בחירת תפקיד. הסיסמאות נשמרות כ־bcrypt Hash עם work factor 12. ה־JWT כולל תוקף, מנפיק וקהל יעד; זהות ותפקיד נבדקים מול מסד הנתונים. אין Refresh Tokens; לאחר פקיעת תוקף נדרשת התחברות מחדש. סיסמאות, Hash ו־Tokens אינם נכללים בתשובות מידע או בלוגים.

עד 20 ניסיונות התחברות/הרשמה מכל כתובת בתוך 15 דקות, עד 300 בקשות API בדקה ועד 20 פעולות העלאה/עריכה של מנהל בדקה. המונים נמצאים בזיכרון ומיועדים למופע שרת יחיד. בפריסה למספר מופעים יש לעבור לאחסון מגבלות משותף.

TRUST_PROXY_HOPS הוא 0 מקומית ו־1 בפריסה מאחורי הפרוקסי של Render. אין להגדיל אותו ללא בדיקת מבנה הרשת. CORS אינו תחליף להרשאות; קריאות שאינן דפדפן עדיין מחייבות Token כשנדרש.

קבצים אינם מורצים או מוצגים כ־HTML. ההגנה כוללת סיומת, גודל, UTF-8 ותוכן JSON תקין; אין סריקת אנטי־וירוס או הבטחה לאיכות ההנחיות. מנהל צריך לבדוק את התוכן לפני פרסום. אין לכלול סודות בקובצי משאבים.

מועדי יצירה ועדכון נשמרים להכנת מיון עתידי. בחירת מיון, דירוגים, צ׳אט ומדריכים נפרדים אינם חלק מהגרסה הזו. רשימת ההרחבות נמצאת ב־[docs/EXTENSIONS.md](docs/EXTENSIONS.md).
